# PHANTOM

Локальное приложение для шифрования и сокрытия текста или файла в PNG, WAV или FLAC. Исходные данные не передаются в сеть приложением.

## Установка и запуск

Нужен Python **3.10 или новее** с работающим Tkinter. На macOS Apple Silicon удобно использовать официальный установщик Python для macOS; проверьте наличие Tk командой `python3 -m tkinter`. Если окно не появилось, установите Python со встроенным Tk. На Linux могут понадобиться системные пакеты Tk, libsndfile и шрифты с поддержкой кириллицы. Для запуска потребуется графическая сессия.

```bash
git clone https://github.com/laos55515-max/Phantom.git
cd Phantom
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py
```

На Windows вместо `source .venv/bin/activate` используйте `.venv\Scripts\activate`. Предоставляемый `Phantom.spec` предназначен для сборки macOS-приложения при помощи PyInstaller и требует отдельной проверки сборки на целевой версии macOS.

## Использование

1. Во вкладке **Изображения** выберите «Скрыть» или «Извлечь». Во вкладке **Аудио** доступны обе операции.
2. Выберите носитель кнопкой или перетащите его на соответствующую область. Для сокрытия выберите текст либо файл, введите пароль длиной не менее 12 символов и сохраните результат в отдельный файл.
3. Для извлечения откройте сохранённый результат и введите тот же пароль. Файл можно сохранить в выбранную папку, текст появится в окне приложения.

PNG и аудио могут содержать меньше данных, чем их размер на диске. Оценка для данных до сжатия приблизительная: точная проверка выполняется перед записью. Шифрование и работа с носителем идут в фоновом потоке. Индикатор отображает обработанные биты, сэмплы или байты для текущего этапа. На этапах PBKDF2, сжатия и сохранения PNG библиотека не сообщает процент, поэтому индикатор показывает неопределённое ожидание.

## Форматы

| Носитель | Поддержка | Как встраиваются данные |
|---|---|---|
| PNG | Неподвижный PNG, включая прозрачность; до 40 мегапикселей | LSB Matching (±1) в RGB; прозрачность не меняется |
| WAV / WAVEX | Целочисленный PCM: 8, 16, 24 или 32 бит | Один младший бит каждого сэмпла |
| FLAC | Целочисленный PCM, поддерживаемый libsndfile, обычно 8, 16 или 24 бит | Один младший бит каждого сэмпла |
| JPEG, MP3, AAC, OGG/Vorbis, WAV с float-сэмплами, анимированный PNG | Не поддерживаются | — |

Выходное аудио сохраняется в том же типе контейнера и PCM, что и входное. Метаданные изображений и дополнительные аудиочанки могут не сохраниться. Скрытый файл или текст ограничен 64 МиБ до сжатия. Сохранённый файл не следует обрезать, редактировать, изменять его размер или перекодировать с потерями: скрытые данные, скорее всего, повредятся.

## Безопасность и совместимость

- Новые данные шифруются AES-256-GCM. Ключ выводится из пароля через PBKDF2-HMAC-SHA256 с 600 000 итерациями и случайной солью; nonce также случайный. Проверка целостности выполняется до выдачи расшифрованных данных. Сравнение дополнительного SHA-256 использует `hmac.compare_digest`.
- Старые PNG, созданные исходной версией PHANTOM с **200 000** итерациями, по-прежнему читаются при условии соблюдения указанных выше ограничений. Старая версия программы не умеет читать новый формат. Проверяйте резервные копии до удаления старой программы или исходников.
- Стеганография **не гарантирует незаметности**: данные размещаются последовательно и могут обнаруживаться статистическим анализом. Шифрование защищает содержимое при достаточно сильном пароле, но не скрывает сам факт наличия данных и не защищает от подбора слабых паролей. Новая версия сохраняет заметный служебный маркер внутри встроенной полезной нагрузки.
- Перезапись перед удалением оригинала — необязательная операция **без гарантии стирания**, особенно на SSD, в снимках, облачной синхронизации и резервных копиях. Перед удалением программа перечитывает стегофайл и сверяет данные; при ошибке перезаписи оригинал может быть повреждён. В Windows эта функция может быть недоступна.
- Обычные строки и байты Python не гарантируют надёжное стирание пароля или расшифрованных данных из оперативной памяти. Приложение не проходило независимый криптографический аудит и не является гарантией абсолютной безопасности.

Светлая и тёмная темы переключаются без перезапуска. Поддержка системной темы зависит от ОС и возможностей CustomTkinter; на некоторых рабочих столах Linux режим «Системная» может использовать светлую тему. Если нативный модуль перетаскивания недоступен, используйте выбор файлов кнопками.

## Тестирование

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют циклы текста и файлов, WAV/FLAC и глубину PCM, старые PNG, неверный пароль, повреждение данных, прозрачность, ёмкость, валидацию форматов и ограничения распаковки. Проверки GUI и сборки на конкретной версии macOS выполняются отдельно.
